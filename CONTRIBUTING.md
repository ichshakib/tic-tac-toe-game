# Contributing to Tic-Tac-Toe Royale

First off, thank you for considering contributing to **Tic-Tac-Toe Royale**! 🎉

Contributions from the community help make this project better for everyone. Whether you're fixing a bug, improving documentation, or adding a new feature, your help is greatly appreciated.

---

## 📋 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](./CODE_OF_CONDUCT.md). Please read it to understand our community standards.

---

## 🚀 How to Contribute

### 1. Reporting Bugs

If you find a bug or unexpected behavior:
1. Check the [GitHub Issues](https://github.com/ichshakib/tic-tac-toe-game/issues) to make sure it hasn't already been reported.
2. If it's a new bug, open a new issue with:
   - A clear, descriptive title.
   - Steps to reproduce the issue.
   - Expected behavior vs. actual behavior.
   - Browser name, version, and device OS.
   - Screenshots or console logs if applicable.

### 2. Suggesting Enhancements

Feature requests and design suggestions are always welcome:
1. Open an issue on GitHub describing the feature you'd like to see.
2. Explain why this enhancement would be useful.
3. Provide mockups, sketches, or code concepts if available.

### 3. Submitting Pull Requests

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/tic-tac-toe-game.git
   cd tic-tac-toe-game
   ```
3. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**:
   - Maintain the zero-dependency architecture (Pure HTML5, Vanilla CSS3, and ES6+ JavaScript).
   - Ensure UI responsiveness across mobile, tablet, and desktop screens.
   - Keep code clean, accessible, and well-structured.
5. **Test your changes** in modern web browsers (Chrome, Firefox, Safari, Edge).
6. **Commit your changes** with a clear commit message:
   ```bash
   git commit -m "feat: add sound effect customization slider"
   ```
7. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request** against the `main` branch of the upstream repository.

---

## 🛠️ Development Guidelines

- **Zero External Dependencies**: All core game features (AI, game state machine, audio synthesizer, multiplayer sync) must run natively in standard web browsers without requiring Node.js dependencies, build steps, or backend databases.
- **Design System Consistency**: Follow the existing palette (Emerald Green `#10b981`, Warm Coral `#f97316`, neutral dark/light backgrounds) and Lucide icon conventions.
- **Clean Documentation**: Avoid redundant header comments; include concise, helpful inline comments where necessary.
